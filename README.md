# MERN Task Management App

A full-stack Task Management Web Application built using MongoDB, Express.js, React.js, and Node.js.

## Features

- User registration and login
- JWT authentication
- Protected routes
- Add, edit, delete, and view tasks
- Mark tasks as completed or pending
- Search tasks
- Filter by status
- Pagination
- Responsive UI

## Tech Stack

### Frontend
- React.js
- React Router
- Axios
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcryptjs
